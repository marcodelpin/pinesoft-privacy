プライバシーポリシー

アプリ： GiroGruppi
開発者： PineSoft
最終更新日： 2026年10月1日

GiroGruppi は、入力した人物のリストからバランスの取れたグループを作成し、セッションごとに入れ替えます。入力した人物、グループ、履歴は端末内に保存されます。

概要

入力した人物、グループ、履歴は端末内に保存されます。アカウントも PineSoft のサーバーもなく、PineSoft はこれらのデータを一切受け取りません。アプリには Google AdMob のバナー広告が 1 つ表示され、Google の広告 SDK が下記「広告」の項目に記載のとおり一部の端末データを収集します。

アカウントなし、PineSoft のサーバーなし

アプリは登録やログインを必要とせず、データを PineSoft のサーバーに送信しません。リストやグループは接続なしで使えます。インターネットは、広告の読み込みと、購入した場合の「広告を削除」の購入処理にのみ使用します。

端末に保存されるデータ

入力した名前、タグ、グループ、設定は、端末内のアプリ専用ストレージにあるローカルファイルに保存されます。共有を選択しない限り、これらのデータが端末の外に出ることはありません。アプリをアンインストールするか、データを消去すると削除されます。

共有とバックアップ

GiroGruppi は、ご自身が操作したときのみ、システムの共有メニューを通じてデータを共有します。

  • バックアップ：すべてのデータを含む JSON ファイル（girogruppi-backup.json）。
  • エクスポート：作成したグループを含む CSV ファイルまたはプレーンテキスト。

共有先のアプリはご自身で選びます。データを受け取り、そのアプリ自身のプライバシーポリシーに従って扱うのは、PineSoft ではなくそのアプリです。バックアップは、そのテキストをアプリに貼り付けて復元します。

広告(Google AdMob)

PineSoft の GiroGruppi は、Google AdMob が提供するバナー広告を 1 つ表示します。表示されるのはパーソナライズされていない広告のみです。

欧州経済領域、英国、スイスでは、Google の User Messaging Platform を通じて同意を取得します。選択内容は、アプリのメニューの"Privacy options"からいつでも確認・変更できます。

広告の配信、効果測定、不正防止のため、Google Mobile Ads SDK は端末から次のデータを収集し、Google と共有します。

  • 広告 ID およびその他の端末識別子
  • IP アドレス(おおよその位置情報を推定できる場合があります)
  • 広告の表示やタップなどのアプリ操作、および診断情報

Google はこれらのデータを広告、分析、不正防止のために使用します。データは転送中に暗号化されます。PineSoft はこれらを受け取りません。

パートナーのサイトやアプリを使用する際の Google によるデータの使用方法

「広告を削除」の購入

任意の「広告を削除」の購入は Google Play が処理します。PineSoft は支払いデータを受け取りません。

お子様

GiroGruppi は 13 歳未満のお子様を対象としておらず、PineSoft は 13 歳未満のお子様の個人データを意図的に収集しません。

ご自身での管理

リストとグループは端末内に保存されるため、すべてご自身で管理できます。項目の編集や削除、バックアップの書き出し、アプリのデータ消去またはアンインストールによる全削除が可能です。広告に関する同意はメニューの"Privacy options"から変更でき、広告 ID は端末の設定でリセットできます。

本ポリシーの変更

本ポリシーが変更された場合は、このページと日付を更新します。
